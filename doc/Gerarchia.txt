1. **Solo Opus assegna i tool/plugin/skill**. Sonnet e i Worker non possono mai modificarli, aggiungerli o rimuoverli.
2. **Sonnet è il gate obbligatorio**. Nessun output dei Worker raggiunge Opus senza validazione tecnica e verifica toolchain.
3. **Max 3 iterazioni Worker ↔ Sonnet**. Al 4° fallimento, Sonnet scala a Opus con report strutturato.
4. **Routing automatico per complessità**:
   - `Semplice/Boilerplate/<200 righe` → Builder (BigModel GLM-4.7-Flash)
   - `Complesso/Logica critica/Stato avanzato` → Executor (Z.AI GLM-5.1)
   - `Ambiguo/Critico` → Analisi Sonnet → Escalation Opus
5. **Zero comunicazione diretta Utente ↔ Worker**. Tutto transita per la gerarchia.
6. **Opt-in via configurazione**: Il sistema gerarchico si attiva solo se esplicitamente abilitato nel config di Paperclip.
