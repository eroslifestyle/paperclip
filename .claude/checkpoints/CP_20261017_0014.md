## Code Context

`~/.local/bin/paperclip-launch` (verbatim):

```sh
#!/bin/sh
# Avvia Paperclip (se non gia' attivo) e lo apre come app autonoma (Chromium --app, profilo dedicato)
URL=http://127.0.0.1:3100
if ! curl -s -m 2 "$URL/api/health" >/dev/null 2>&1; then
  nohup "$HOME/.local/bin/paperclipai" run --bind loopback >/tmp/paperclip-run.log 2>&1 &
  i=0
  while [ $i -lt 60 ]; do
    curl -s -m 2 "$URL/api/health" >/dev/null 2>&1 && break
    sleep 2; i=$((i+1))
  done
fi
exec /usr/bin/chromium --app="$URL" --class=paperclip --name=paperclip \
  --user-data-dir="$HOME/.local/share/paperclip-app" \
  --no-first-run --no-default-browser-check --disable-features=Translate
```
